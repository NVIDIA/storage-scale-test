# Contributing to NVIDIA Storage Scale Test

This project is not currently accepting external code contributions or pull
requests. Maintainers may close unsolicited pull requests without review.

Bug reports, documentation corrections, and feature suggestions are welcome.
Use the appropriate form in the [GitHub issue template directory](.github/ISSUE_TEMPLATE/)
and do not include confidential information, credentials, or sensitive system
details.

Before participating, read and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
Report suspected vulnerabilities privately as described in the
[Security Policy](SECURITY.md), not through a public issue or pull request.
